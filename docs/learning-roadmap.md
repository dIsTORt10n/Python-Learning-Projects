# Learning Roadmap

This roadmap helps you move through the repository in a clear learning order.

## Beginner level

Start with the basics directory and focus on:

- variables and values
- user input
- arithmetic and formatting
- if/else conditions
- loops
- functions
- lists and dictionaries

Suggested files:

- `basics/multiplication_table.py`
- `basics/reverse_sentence.py`
- `basics/number_to_words.py`

## Intermediate level

After the basics, move to small logic-based projects and games:

- `games/hangman_game.py`
- `games/coin_game.py`
- `games/rock_paper_scissors.py`

Focus on:

- user interaction flow
- game state handling
- validation and input checking
- repeated logic in loops

## Application level

Once you are comfortable with logic, work on app-style programs:

- `apps/user_management_system.py`
- `apps/to_do_list.py`

Focus on:

- data storage
- structured code
- reusable functions
- menu-driven programs

## Automation level

Move into scripts that work with real-world data:

- `automation/web_scraper.py`

Focus on:

- HTTP requests
- parsing HTML
- saving output to files
- basic data handling

## Utility level

Use utility scripts to practice practical Python patterns:

- `utilities/password_generator.py`
- `utilities/recipe_collection.py`

These are good examples of writing small tools that solve simple problems.

## Suggested progression

1. Basics
2. Games
3. Apps
4. Automation
5. Utilities

This order helps build confidence while gradually introducing more complex code patterns.
